# Serazum.com portfolio website

A responsive, one-page static HTML portfolio for Serazum Munir, an independent lead enrichment specialist.

## Before publishing
1. Open `index.html`.
2. Replace the general Upwork and Freelancer links with your actual profile URLs.
3. Confirm the contact email. The current button uses `hello@serazum.com`; create that mailbox or a forwarding address before publishing, or replace it with an email you already use.
4. Review the copy and make sure every statement reflects your actual service.
5. The example table is illustrative only. If you add a real sample, only share data you have permission to disclose and mask personal information.

## Publish using GitHub Pages
1. Create a **public** GitHub repository named `YOUR-GITHUB-USERNAME.github.io`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages** and publish from the `main` branch and `/ (root)`.
4. After the default GitHub Pages URL works, enter `serazum.com` under **Settings → Pages → Custom domain**.
5. At your domain registrar, set DNS records exactly as described in GitHub's official guide: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site
6. Wait for DNS propagation, then enable **Enforce HTTPS** in Pages settings when available.

GitHub Pages hosts static files for free. The email button opens the visitor's email app; it does not process a form or send mail on its own.
